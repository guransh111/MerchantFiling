# 11. Glossary

## Payments and India

| Term | Meaning |
|---|---|
| **UPI** | Unified Payments Interface: India's instant bank-to-bank payment system (QR codes, UPI IDs like `shop@okbank`) |
| **NPCI** | National Payments Corporation of India: runs UPI |
| **PA / payment aggregator** | Company that collects payments for merchants and settles to them (Razorpay, Cashfree…). Regulated by RBI |
| **P2M / P2P** | Person-to-merchant / person-to-person payments. PAs see P2M |
| **Settlement, T+1, T+2** | Paying collected money to the merchant's bank: next day / two days later |
| **Rolling reserve** | Holding back a % of each settlement for a period as a safety buffer |
| **KYC / KYB** | Know Your Customer / Business: identity and document checks |
| **MCC** | Merchant Category Code: the business type label on a merchant account |
| **Kirana** | Neighbourhood grocery store |
| **Mule account** | Account used to receive or move criminal money, often rented from a real person |
| **Front / transaction laundering** | A merchant account pretending to be one business while processing payments for another (here: betting) |
| **Tier-1/2/3 city** | Metros / large cities / smaller cities |

## Regulators and law

| Term | Meaning |
|---|---|
| **RBI** | Reserve Bank of India; issues the Payment Aggregator Directions |
| **PMLA** | Prevention of Money Laundering Act, 2002: requires suspicious-activity reporting |
| **FIU-IND** | Financial Intelligence Unit: receives suspicious transaction reports (STRs) |
| **ED** | Enforcement Directorate: investigates money laundering (1xBet, Parimatch cases) |
| **I4C / Suspect Registry** | Indian Cyber Crime Coordination Centre; a shared list of suspect accounts |
| **DPDP Act** | Digital Personal Data Protection Act, 2023: India's privacy law |
| **MuleHunter.AI** | RBI Innovation Hub's AI tool that banks use to find mule accounts |
| **Puttaswamy** | 2017 Supreme Court judgment making privacy a fundamental right; proportionality test |

## Statistics and data

| Term | Meaning |
|---|---|
| **Synthetic data** | Data generated by a program to resemble reality |
| **Feature / signal** | One number summarising behaviour (e.g. night share) |
| **Median** | Middle value; unaffected by extremes |
| **MAD** | Median absolute deviation: a robust measure of spread (× 1.4826 ≈ standard deviation) |
| **z-score** | How many "typical spreads" a value is from normal |
| **Peer group** | Merchants with the same declared category and city tier |
| **Entropy** | Measure of variety/unpredictability; low = a few repeated values |
| **Drift** | Gap between declared and observed behaviour |
| **Precision / recall** | Share of flags that are right / share of bad cases flagged |
| **False positive** | Honest merchant flagged |
| **Label / ground truth** | The real answer (front or not), known here because we simulated it |
| **Leakage** | Accidentally letting the answer into the inputs; makes results look falsely good |
| **Graph / network** | Dots (merchants) joined by lines (shared phones, accounts, customers) |
| **Personalized PageRank** | Spreads importance from chosen starting points along a network's lines |
| **Seed** (two meanings) | (1) known-bad merchants PageRank starts from; (2) random-number seed (42) that makes results reproducible |
| **Supervised ML / XGBoost / gradient boosting** | Models that learn from labelled examples; a later phase |

## Code tools

| Term | Meaning |
|---|---|

| **networkx** | Python library for networks |
| **Streamlit** | Turns a Python script into a web dashboard |
| **pytest** | Runs automated checks |
| **CSV** | Plain-text table file; opens in Excel |
